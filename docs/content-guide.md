# 문제 준비 안내

팀마다 말씀 1개와 문제 5개가 필요합니다. 8팀이면 문제 40개입니다. 스프레드시트에 작성해 CSV로 내려받은 뒤 게임에서 가져옵니다.

## 작성 순서

1. **템플릿 열기** — `data/content-template.csv`를 구글 시트에서 엽니다 (파일 → 가져오기 → 업로드 → "스프레드시트 바꾸기"). 엑셀은 파일을 바로 열면 됩니다.
2. **작성하기** — 예시 2세트(요한복음 3:16, 시편 23:1)를 참고해 한 행에 문제 하나씩 적습니다. 기차역 갈림길이 말씀 10개이므로 **10세트 × 5문제 = 50행**을 만듭니다(팀 수 이상이면 됨). 말씀 출처가 갈림길 표지판에 그대로 보입니다. 첫 행(칸 이름)은 지우거나 바꾸지 마세요.
3. **CSV로 내려받기**
   - 구글 시트: 파일 → 다운로드 → 쉼표로 구분된 값(.csv)
   - 엑셀: 다른 이름으로 저장 → 파일 형식 **"CSV UTF-8(쉼표로 분리)"** (그냥 "CSV"로 저장하면 한글이 깨집니다)
4. **가져오기** — 게임의 관리 화면에서 문제 가져오기로 CSV 파일을 고릅니다. 오류가 있으면 "3행(세트 set-1 문제 2)"처럼 시트의 행 번호로 알려 줍니다. 고친 뒤 다시 내려받아 가져오세요.
5. **검수** — 관리 화면의 문제 세트 검수에서 실제 출제 순서대로 문제와 정답을 확인합니다.

## 칸 작성 규칙

| 칸 | 적는 내용 |
|---|---|
| 세트ID | 말씀 하나에 붙이는 이름. 같은 말씀의 5문제는 같은 세트ID를 씁니다. 예: `set-1` |
| 말씀 출처 / 말씀 원문 | 세트의 **첫 행에만** 적어도 됩니다. 원문은 관리자 검수 화면에만 보입니다. |
| 문제 번호 | 1~5. 이 번호 순서로 출제됩니다. 행 순서는 상관없습니다. |
| 문제 | 빈칸을 넣은 말씀 문장 |
| 보기1~보기5 | 화면에 1~5번으로 표시됩니다. |
| 정답 번호 | 정답 보기의 번호 1~5 (`3` 또는 `3번`) |

### 빈칸 표기
- 빈칸은 **밑줄 3개 이상 `___`** 로 적습니다. 화면에서 노란색 밑줄로 강조됩니다.
- 조사까지 빈칸에 넣으면 보기를 고르기가 자연스럽습니다. 예: `하나님이 ___ 이처럼 사랑하사` / 보기 `세상을`, `우리를` …
- 성경 번역본(예: 개역개정)과 띄어쓰기를 모든 세트에서 통일하세요. 정답을 빈칸에 넣었을 때 원문과 똑같아야 합니다.

## 자주 나는 오류

| 메시지 | 해결 |
|---|---|
| 한글이 깨져 있습니다 / 필요한 칸이 없습니다 | 엑셀에서 "CSV UTF-8"로 저장했는지, 첫 행 칸 이름을 바꾸지 않았는지 확인 |
| 문제가 5개여야 하는데 4개입니다 | 세트ID 오타로 한 문제가 다른 세트로 갔는지 확인 |
| 문제 번호 N이(가) M행과 중복됩니다 | 같은 세트 안에서 문제 번호를 1~5로 한 번씩만 사용 |
| 정답 번호는 1~5 사이 숫자여야 합니다 | 정답 칸에 보기 문구가 아니라 번호를 적기 |
| 질문에 빈칸 표시가 없습니다 | 문제 칸에 `___`(밑줄 3개 이상) 추가 |
| 보기 문구가 비어 있습니다 | 보기 5칸을 모두 채우기 |
| 칸 수가 헤더보다 많습니다 / 큰따옴표가 닫히지 않았습니다 | 시트 프로그램에서 내려받은 CSV를 쓰면 생기지 않습니다. 메모장으로 직접 고칠 때는 쉼표가 든 문구를 `"…"`로 감싸고, 문구 안의 `"`는 `""`로 적습니다. |
| 말씀 출처이(가) 이 세트의 앞 행과 다릅니다 | 같은 세트의 출처·원문은 첫 행에만 적거나 모두 똑같이 적기 |
