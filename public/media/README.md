# 연출 영상 넣는 곳

이 폴더에 아래 이름으로 MP4 파일을 넣으면 게임이 영상을 먼저 재생합니다.
파일이 없거나 재생에 실패하면 자동으로 기본 애니메이션과 효과음으로 대신합니다. 영상이 없어도 게임은 문제없이 진행됩니다.

| 파일명 | 언제 나오나 | 권장 길이 |
|---|---|---|
| `intro.mp4` | 행사 첫 도전 때 한 번 (꿈에서 깨어 기차역) | 6~9초 |
| `correct.mp4` | 정답을 맞혔을 때 | 1.5~2초 |
| `wrong.mp4` | 오답일 때 (정답을 보여주면 안 됨) | 1~1.5초 |
| `inferno.mp4` | 목숨을 모두 잃었을 때 (불구덩이) | 4~6초 |
| `heaven.mp4` | 5문제를 모두 맞혔을 때 (천국) | 4~6초 |

- 파일명은 위와 똑같이 영어 소문자로 씁니다.
- `intro`·`heaven`·`inferno`는 영상이 있으면 영상만 재생하고 끝납니다. 기본 애니메이션에 있는 대사 상자와 클릭 대기는 나오지 않으니, 필요한 대사는 영상 안에 넣어 주세요.
- 오답 영상이 끝나면 게임이 하트가 깨지는 장면(0.7초)을 자동으로 이어서 보여줍니다. 영상에 하트 장면을 넣지 않아도 됩니다.

## 영상 규격

- 형식: MP4 (H.264 영상 + AAC 소리)
- 해상도: 1920×1080 (16:9). 다른 비율도 재생되지만 위아래나 양옆에 검은 띠가 생깁니다.
- 프레임: 30fps 권장
- 용량: 파일당 20MB 이하 권장
- 소리: 효과음을 영상 안에 넣어 주세요. 게임은 영상 소리를 그대로 틀고, 관리 메뉴의 음량 설정을 따릅니다.
- 영상이 시작되는 데 2.5초가 넘게 걸리면 기본 애니메이션으로 넘어갑니다.

## 바꾼 뒤 확인

1. 브라우저를 새로고침합니다.
2. 연습 팀으로 정답과 오답을 한 번씩 눌러 영상과 소리가 나오는지 봅니다.
3. 한 번 재생에 실패한 영상은 새로고침 전까지 다시 시도하지 않습니다. 파일을 고쳤다면 새로고침하세요.

## 컴퓨터가 느릴 때

불구덩이·천국 애니메이션이 끊기면 주소 끝에 `?lite=1`을 붙여 여세요. 예: `http://localhost:5173/?lite=1`
주소에 이미 `?`가 있으면 `&lite=1`로 붙이세요.
가벼운 효과로 바뀝니다.
