# 말씀 암송 퀴즈쇼

팀마다 말씀 구절 하나로 5문제에 도전하는 예능 퀴즈쇼형 웹게임. TV(HDMI)에 브라우저를 띄우고 관리자가 마우스로 진행한다.

스토리(픽셀아트): 깊은 꿈 → 눈을 떠보니 지하 기차역(행사 첫 도전 때만 인트로) → 팀이 갈림길 10개 중 말씀 하나 선택(고른 길은 닫힘) → 지하를 달리는 기차 안에서 5문제 → 모두 맞히면 천국 엔딩, 목숨을 다 잃으면 불구덩이 후 악몽에서 깨어나는 엔딩. 엔딩 대사가 끝나면 화면을 클릭해 넘어간다.

## 행사 당일 실행

```bash
source ~/.nvm/nvm.sh
npm run build            # dist/ 생성 (처음 한 번, 코드 바뀌면 다시)
npx vite preview --port 8080
```
브라우저(Chrome 권장)에서 `http://localhost:8080` → **시작** 클릭(전체화면 + 소리 켜짐).
PC가 느리면 `http://localhost:8080/?lite=1`.

> `dist/index.html`을 파일로 직접 열면 동작하지 않는다. 반드시 위처럼 서버로 연다.

## 준비물
- **문제 데이터**: 초기 설정 화면의 "CSV 템플릿 받기" → 구글 시트/엑셀에서 작성 → CSV로 저장 → "문제 파일 가져오기". 작성법: `docs/content-guide.md`
- **연출 영상(선택)**: `public/media/README.md` 참고. 없으면 내장 연출과 효과음으로 진행.

## 운영 팁
- 진행 상황은 브라우저에 자동 저장된다. 새로고침하거나 브라우저를 다시 열면 **이어하기**.
- 문제 화면 왼쪽 아래 ⚙ 아이콘 → 관리 메뉴(되돌리기, 연출 건너뛰기, 음량, 전체화면). 메뉴가 열리면 진행이 멈춘다.
- 리허설 후에는 관리 → **전체 기록 초기화** (팀명과 문제는 유지).
- 같은 PC·같은 브라우저에서 진행해야 기록이 유지된다.
